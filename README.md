# 우리집 가계부 (폰 가계부 웹앱)

폰에서 쓰는 무료 가계부예요. 링크를 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

- 하루 예산(아낀 돈은 다음 날로), 한 주 예산(일~토, 1일이 든 주가 1주차), 비상금 예산
- 쓴 내역·달력(구분별 색), 적금(형광펜), 카드 할부(회차·남은 돈 자동 계산)
- 수입·고정 지출·교육비 등 달별 기록, 지난달 항목 자동으로 이어 쓰기
- 그래프(어디에 썼나·주차별·월별 항목별), 엑셀 내려받기
- 내 지출 구분 직접 만들기

## 기록은 어디에 저장되나요?
**이 폰(브라우저) 안에만** 저장돼요. 로그인도, 서버도 없어서 만든 사람을 포함해 누구도 내 기록을 볼 수 없어요.
그래서 폰을 바꾸거나 브라우저의 사이트 데이터를 지우면 기록이 사라져요. **⚙ 설정 → 백업 파일 저장**을 가끔 해 두고, 새 폰에서는 **백업 불러오기**로 이어 쓰세요.

## 설치
1. 이 주소를 크롬(아이폰은 사파리)으로 열기
2. 크롬: ⋮ → **홈 화면에 추가** / 사파리: 공유 버튼 → **홈 화면에 추가**
